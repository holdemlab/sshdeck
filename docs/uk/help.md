# sshdeck — довідка

Менеджер SSH-сесій з вкладками. Ліворуч дерево сесій, праворуч термінал
активної вкладки, зверху вкладки, унизу підказки.

**Головне правило:** коли фокус у терміналі, усі клавіші йдуть на сервер. Самим
sshdeck керує **prefix**: `ctrl+a`, потім команда. Prefix можна змінити в
налаштуваннях (`ctrl+a ,`).

> Ця довідка відкривається через `ctrl+a ?` або `?` у сайдбарі.
> Прокрутка: `↑↓` `j k`, `pgup pgdn`, `g G`; пошук `/`, далі `n`; вихід `esc` або `q`.

## Швидкий старт

1. `N` — створити папку (`/name` — на верхньому рівні, `a/b` — вкладені).
2. `n` — нова сесія: Назва, Хост, Користувач, Файл ключа; зберегти `ctrl+s`.
3. `enter` — підключитися. Нова вкладка спитає про ключ сервера (`yes` або `так`) і,
   якщо треба, пароль.
4. `ctrl+a s` — повернутися до дерева; `ctrl+a 1`…`9` — перейти на вкладку.
5. Набридло вводити пароль? `ctrl+a k` встановить твій ключ на сервер.

## Prefix-команди

Працюють завжди: і в терміналі, і в дереві.

| Клавіші | Дія |
|---|---|
| `ctrl+a 1`…`9` | перейти на вкладку |
| `ctrl+a n` / `ctrl+a p` | наступна / попередня вкладка |
| `ctrl+a s` | фокус: дерево ↔ термінал |
| `ctrl+a b` | сховати / показати дерево |
| `ctrl+a w` | закрити вкладку |
| `ctrl+a r` | перепідключити закриту вкладку |
| `ctrl+a d` | ще одна вкладка з тією ж сесією |
| `ctrl+a t` | тунелі вкладки |
| `ctrl+a e` | редагувати сесію вкладки |
| `ctrl+a k` | встановити свій ключ на сервер |
| `ctrl+a [` | прокрутка історії |
| `ctrl+a ,` | налаштування |
| `ctrl+a ?` | ця довідка |
| `ctrl+a q` | вийти |
| `ctrl+a ctrl+a` | надіслати сам `ctrl+a` на сервер |

## Дерево сесій

| Клавіші | Дія |
|---|---|
| `↑↓` `j k` | рух |
| `←` `h` / `→` `l` | згорнути / розгорнути папку |
| `H` або `-` / `L` або `*` | згорнути / розгорнути **всі** |
| `enter` | відкрити сесію (на папці — згорнути / розгорнути) |
| `t` | відкрити тільки тунелі, без shell |
| `/` | пошук за назвою, шляхом, хостом |
| `n` | нова сесія |
| `N` | нова папка (`a/b` вкладені, `/name` на верхньому рівні) |
| `R` | перейменувати на місці |
| `e` | редагувати сесію або папку (форма) |
| `C` | кольори: текст і заливка (напр. `prod` червоним) |
| `c` | дублювати поруч |
| `y`, потім `p` | копіювати у вибрану папку (`P` — на верхній рівень) |
| `x`, потім `p` | перенести у вибрану папку (`P` — на верхній рівень) |
| `d` | видалити (з підтвердженням) |
| `E` | відкрити `sessions.yaml` у редакторі |
| `r` | перечитати `sessions.yaml` |
| `tab` | до терміналу |
| `q` | вийти |

Згорнуті папки запам'ятовуються між запусками.

## Форми

| Клавіші | Дія |
|---|---|
| `tab` / `shift+tab`, `↑↓` | між полями |
| `ctrl+s` | зберегти |
| `esc` | вийти (якщо щось змінено, спитає: `y` викинути, `s` зберегти, `n` назад) |
| `ctrl+u` | стерти текст до курсора |

## Успадкування

`user`, `port`, `jump` і `key file` задаються на папці й діють на все
всередині. Перемагає найближче значення: **сесія → папка → … → корінь**. Що
вийшло в підсумку, видно під деревом (`user@host`, `через …`).

## Jump-хости

Поле **Jump** — це шлях до іншої сесії (`infra/proxy`) або рядок
`user@host:port`. Кілька хостів через кому дають ланцюжок.

- Кожен хост авторизується **своїм** ключем, зі твоєї машини; ключ цільового
  сервера на jump-хост класти не треба.
- Якщо на jump інший ключ, оформи jump **окремою сесією** зі своїм «Файл ключа» і
  послися на неї. Рядок `user@host` бере ключ цільового сервера.
- Перейменування й переміщення сесій автоматично оновлюють посилання `jump`.

## Ключі та паролі

Порядок спроб: **ключ сесії → ssh-agent → ключі з налаштувань → пароль**.

- Passphrase ключа питається лише тоді, коли сервер цей ключ прийняв.
- Яким ключем увійшли, видно у вкладці: `Пробую ключ …`.
- Прийняті паролі й passphrase пам'ятаються **в пам'яті** до виходу з
  sshdeck: перепідключення не питають. На диск нічого не пишеться. Вимикається
  налаштуванням `remember_passwords`.
- `ctrl+a k` дописує твій публічний ключ у `~/.ssh/authorized_keys` на сервері
  (як `ssh-copy-id`). Якщо ключа немає, sshdeck створить новий і може
  прописати його в сесію.

Ключі серверів зберігаються у власному `known_hosts`. Новий сервер показує
відбиток і питає `yes/no, так/ні`. Якщо ключ сервера змінився, sshdeck відмовляється
підключатися.

## Тунелі

Формат як у ssh:

| Запис | Що робить |
|---|---|
| `L 5432:localhost:5432` | локальний порт → сервіс на сервері |
| `L 8080:grafana.internal:3000` | локальний порт → хост, видимий із сервера |
| `D 1080` | SOCKS5-проксі через сервер |
| `R 9000:localhost:3000` | порт на сервері → сервіс на твоїй машині |

- Тунелі сесії (поле **Тунелі**) стартують разом із з'єднанням.
- `ctrl+a t` — панель тунелів: `space` вмикає й вимикає, `a` додає, `x`
  видаляє, `w` зберігає в сесію.
- `t` у дереві відкриває сесію тільки для тунелів, без shell.

## Вкладки

| Позначка | Стан |
|---|---|
| `◌` | підключається або чекає на пароль |
| `●` | підключено |
| `✗` | закрито; `r` перепідключає |
| `⇄2` | працюють 2 тунелі |

Прокрутка історії: `ctrl+a [`, далі `↑↓` `pgup pgdn` `g G`, вихід `esc`.
Виділення й копіювання тексту працюють засобами твого терміналу.

## Мова

Українська або англійська: `ctrl+a ,` → **Мова** (`авто` бере мову з `$LANG`).
Перемикається одразу, разом із цією довідкою.

## Кольорові позначки

`C` на папці чи сесії: `← →` колір, `↑↓` текст / заливка, `enter` зберегти.
Позначка папки діє на все всередині й видна на вкладках, тож `prod` не
сплутаєш зі `staging`. У `sessions.yaml` це `color:` і `fill:` (назва з
палітри, `#rrggbb` або `none`).

## Кольори

`ctrl+a ,` → **Тема**: `термінал` (кольори твого термінала) або Catppuccin
`Latte` (світла), `Frappé`, `Macchiato`, `Mocha`. Схема видна одразу під час
вибору й фарбує також програми у вкладках.

## Файли

| Файл | Що в ньому |
|---|---|
| `~/.config/sshdeck/sessions.yaml` | сесії й папки |
| `~/.config/sshdeck/config.yaml` | налаштування (`ctrl+a ,` або `ctrl+e` там же для редактора) |
| `~/.config/sshdeck/known_hosts` | ключі серверів |
| `~/.local/state/sshdeck/state.yaml` | які папки згорнуті |

## Якщо щось не так

- **`n`, `e`, `d` не працюють:** фокус у терміналі, натисни `ctrl+a s`.
- **`ctrl+a` не доходить до tmux на сервері:** натисни двічі або зміни prefix,
  наприклад на `ctrl+]`.
- **`КЛЮЧ СЕРВЕРА … ЗМІНИВСЯ`** (англійською `HOST KEY … HAS CHANGED`)**:** якщо зміна очікувана, видали вказаний рядок із
  `known_hosts`.
- **`забагато невдалих спроб`** (англійською `too many authentication failures`)**:** задай сесії «Файл ключа» або вимкни
  ssh-agent у налаштуваннях.
