# Клавіші

Екран має три частини:
- таб-бар зверху: `sshdeck`, далі вкладки `1 web-01 ●`, `2 db ⇄1 ●`;
- сайдбар з деревом сесій ліворуч;
- термінал активної вкладки праворуч.

Унизу статус-рядок із підказками.

**Фокус** буває або на сайдбарі, або на терміналі. Коли фокус у терміналі, **усі
клавіші йдуть на сервер**, крім prefix. Prefix за замовчуванням `ctrl+a`; його
можна змінити в [налаштуваннях](settings.md#prefix-і-tmux).

## Prefix-команди (працюють завжди)

Натисни prefix, відпусти, потім клавішу команди. Після prefix статус-рядок
підсвічується і показує доступні команди.

| Після prefix | Дія |
|---|---|
| `1`–`9` | перейти на вкладку з цим номером |
| `n` / `→` / `tab` | наступна вкладка |
| `p` / `←` / `shift+tab` | попередня вкладка |
| `s` | перемкнути фокус: сайдбар ↔ термінал |
| `b` | сховати / показати сайдбар (термінал на всю ширину) |
| `w` / `x` | закрити вкладку (з підтвердженням, якщо з'єднання живе і `confirm_close: true`) |
| `r` | перепідключити закриту вкладку |
| `d` | відкрити ще одну вкладку з тією ж сесією |
| `t` | [панель тунелів](tunnels.md#панель-тунелів-ctrla-t) поточної вкладки |
| `e` | редагувати сесію поточної вкладки |
| `k` | встановити свій публічний ключ на сервер вкладки, щоб далі входити без пароля ([докладніше](authentication.md#встановлення-ключа-на-сервер-ctrla-k)) |
| `,` | [налаштування](settings.md) |
| `[` | режим прокрутки історії (див. нижче) |
| `?` / `h` | довідка (див. [нижче](#довідка-в-програмі)) |
| `q` | вийти (з підтвердженням, якщо є живі з'єднання) |
| prefix ще раз | надіслати сам prefix на сервер (наприклад, `ctrl+a` для bash або tmux) |

## Сайдбар

| Клавіша | Дія |
|---|---|
| `↑↓`, `j k`, `ctrl+p` / `ctrl+n` | рух |
| `g` / `home`, `G` / `end` | на початок / в кінець |
| `←` / `h` | згорнути папку або перейти до батьківської |
| `→` / `l` | розгорнути папку |
| `H` або `-` | згорнути всі папки (курсор переходить на папку верхнього рівня) |
| `L` або `*` | розгорнути всі папки |
| `enter` | відкрити сесію у вкладці; на папці — згорнути / розгорнути |
| `t` | відкрити сесію в режимі [«тільки тунелі»](tunnels.md#режим-тільки-тунелі) |
| `/` | пошук (`enter` відкрити, `esc` скинути, `↑↓` / `tab` вибір) |
| `n` | нова сесія у вибраній папці |
| `N` або `+` | нова папка прямо в дереві, у вибраній; `a/b/c` створює вкладені, `/name` створює на верхньому рівні |
| `R` або `f2` | перейменувати на місці |
| `e` | редагувати сесію або папку (форма) |
| `C` | кольори папки чи сесії: текст і заливка ([докладніше](sessions.md#кольорові-позначки)) |
| `c` | дублювати поруч: сесія — форма копії, папка — копія + перейменування |
| `y`, потім `p` / `P` | копіювати у вибрану папку / на верхній рівень (`p` ще раз — ще одна копія, `esc` завершити) |
| `d` або `delete` | видалити сесію або папку (з підтвердженням) |
| `x`, потім `p` / `P` | перенести у вибрану папку / на верхній рівень |
| `E` | відкрити `sessions.yaml` у редакторі |
| `r` | перечитати `sessions.yaml` |
| `,` | налаштування |
| `?` | довідка |
| `tab` / `esc` | фокус на термінал (якщо є вкладки); `esc` також скидає пошук, переміщення і копіювання |
| `q` / `ctrl+c` | вийти |

Подробиці про редагування дерева: [sessions.md](sessions.md#редагування-в-sshdeck).

## Форми (сесія, папка, налаштування)

| Клавіша | Дія |
|---|---|
| `tab` / `↓`, `shift+tab` / `↑` | наступне / попереднє поле |
| `enter` | наступне поле; на останньому — зберегти |
| `ctrl+s` | зберегти |
| `esc` | скасувати (якщо щось змінено, спершу спитає, див. нижче) |
| `ctrl+u` | стерти текст до курсора |

### Захист від випадкового `esc`

Якщо у формі сесії, формі папки чи на екрані налаштувань щось змінено, `esc`
не закриває її одразу, а питає:

```
Скасувати зміни?  y скасувати · s зберегти · n / esc редагувати далі
```

| Клавіша | Дія |
|---|---|
| `y` | закрити без збереження |
| `s` / `ctrl+s` | зберегти |
| `n`, `esc` або будь-яка інша | повернутися до редагування, введене лишається на місці |

Якщо нічого не змінено, `esc` закриває форму одразу.

Так само працюють:
- рядки в дереві (`N` — нова папка, `R` — перейменування): якщо текст змінено,
  `esc` питає в статус-рядку `Скасувати?  y скасувати · enter зберегти · n редагувати далі`;
- рядок додавання тунелю в панелі тунелів (`a`): якщо щось уже введено, `esc`
  питає `Скасувати тунель?  y скасувати · s додати · n редагувати далі`.

## Вкладка

**Стан у таб-барі:**

| Позначка | Що означає |
|---|---|
| `◌` | підключається (або чекає на пароль чи підтвердження ключа) |
| `●` | підключено |
| `✗` | закрито або помилка; причина є у вкладці та в статус-рядку |
| `⇄N` | активних тунелів |
| `⇄ name` | вкладка в режимі «тільки тунелі» |

**Закрита вкладка:**
- `r` або `enter` перепідключає;
- історія лишається на екрані.

**Режим прокрутки (`prefix [`):**

| Клавіша | Дія |
|---|---|
| `↑↓`, `j k` | на рядок |
| `pgup` / `ctrl+b` / `ctrl+u` | на сторінку вгору |
| `pgdn` / `ctrl+f` / `ctrl+d` / `space` | на сторінку вниз |
| `g` / `G` | на початок / в кінець |
| `esc` / `q` / `enter` | вийти |

У правому верхньому куті видно `прокрутка N/M`. Повноекранні програми (vim, htop) в
історію не пишуть.

**Копіювання і вставка:**
- sshdeck не перехоплює мишу, тож текст виділяється і копіюється засобами твого
  термінала, як зазвичай;
- вставка з буфера передається на сервер; якщо програма на сервері просила
  bracketed paste, вона його отримає.

**Розмір вікна.** Зміна розміру вікна або ховання сайдбару одразу повідомляє
сервер про новий розмір. Поточний розмір видно в статус-рядку, наприклад `88×28`.

## Довідка в програмі

`ctrl+a ?` (або `?` у дереві) відкриває [`help.md`](help.md) з форматуванням
(заголовки, таблиці, код). У тексті підставляється твій prefix, якщо він не
`ctrl+a`. Тема, світла чи темна, вибирається за фоном терміналу.

| Клавіша | Дія |
|---|---|
| `↑↓`, `j k`, `pgup` / `pgdn`, `space` | прокрутка |
| `g` / `G` | на початок / в кінець |
| `/` | пошук (`enter` — знайти) |
| `n` / `N` | наступний / попередній збіг |
| `esc`, `q`, `?` | закрити |
