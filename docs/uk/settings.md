# Налаштування (`config.yaml`)

Файл `~/.config/sshdeck/config.yaml` створюється з коментарями при першому
запуску. Змінювати налаштування можна на екрані налаштувань у sshdeck або
вручну.

## Параметри

| Параметр | За замовчуванням | Допустимі значення | Що робить | Коли діє |
|---|---|---|---|---|
| `language` | `auto` | `auto`, `uk`, `en` | мова інтерфейсу, вбудованої довідки та коментарів у `config.yaml`, див. [нижче](#мова) | одразу |
| `theme` | `terminal` | `terminal`, `latte`, `frappe`, `macchiato`, `mocha` | кольорова схема, див. [нижче](#кольорові-схеми-catppuccin) | одразу |
| `prefix` | `ctrl+a` | клавіша з `ctrl` або `alt`; не `ctrl+c`, `ctrl+m`, `ctrl+i`, `ctrl+[` | командна клавіша у вкладці, див. [keys.md](keys.md) | одразу |
| `sidebar_width` | `32` | 16–120 | ширина дерева сесій, у колонках | одразу |
| `scrollback` | `5000` | 0–1 000 000 | скільки рядків історії тримає кожна вкладка | одразу |
| `term` | `xterm-256color` | непорожній рядок | значення `TERM` для сервера | наступне підключення |
| `connect_timeout` | `15s` | > 0, напр. `10s`, `1m` | таймаут TCP-з'єднання для кожного вузла | наступне підключення |
| `keepalive` | `30s` | `0` вимикає | інтервал keepalive; без відповіді 3 × інтервал з'єднання закривається | наступне підключення |
| `known_hosts` | `~/.config/sshdeck/known_hosts` | шлях | файл ключів серверів, див. [authentication.md](authentication.md#known_hosts) | наступне підключення |
| `use_agent` | `true` | `true` / `false` | брати ключі з ssh-agent (`$SSH_AUTH_SOCK`) | наступне підключення |
| `identities` | `~/.ssh/id_ed25519`, `~/.ssh/id_ecdsa`, `~/.ssh/id_rsa` | список шляхів | ключі, які пробуються для **кожної** сесії після її власного; відсутні файли пропускаються | наступне підключення |
| `remember_passwords` | `true` | `true` / `false` | пам'ятати прийняті паролі й passphrase ключів у пам'яті до виходу; на диск не пишеться; вимкнення стирає запам'ятоване, див. [authentication.md](authentication.md#запамятовування-паролів-у-памяті) | одразу |
| `confirm_close` | `true` | `true` / `false` | питати перед закриттям вкладки з живим з'єднанням | одразу |

Тривалості записуються так: `500ms`, `15s`, `2m`, `1m30s`; `0` означає «вимкнено».

## Екран налаштувань: `ctrl+a ,`

Також відкривається клавішею `,` у сайдбарі.

```
Налаштування  ~/.config/sshdeck/config.yaml

▸ Мова                 ● авто ($LANG)  ○ Українська  ○ English
                       авто — за $LANG · пробіл або ← → змінює
  Тема                 ○ термінал  ○ Latte  ○ Frappé  ○ Macchiato  ● Mocha
  Prefix               ctrl+a
  Сайдбар              32
  Історія              5000
  TERM                 xterm-256color
  Тайм-аут             15s
  Keepalive            30s
  known_hosts          ~/.config/sshdeck/known_hosts
  ssh-agent            [x] увімк.
  Ключі                ~/.ssh/id_ed25519, ~/.ssh/id_ecdsa, ~/.ssh/id_rsa
  Пам'ятати паролі     [x] увімк.
  Питати при закритті  [x] увімк.
```

| Клавіша | Дія |
|---|---|
| `tab` / `shift+tab`, `↑↓` | перехід між полями |
| `enter` на «Prefix» | чекати нову клавішу; наступне натискання стає prefix (`esc` лишає старий) |
| `space`, `enter`, `← →`, `y` / `n` на перемикачах | увімкнути / вимкнути |
| `space`, `enter`, `← →` на «Мова» | наступна / попередня мова |
| `space`, `enter`, `← →` на «Тема» | наступна / попередня схема; вигляд змінюється одразу, ще до збереження |
| `ctrl+s` | зберегти й застосувати |
| `esc` | вийти без збереження; якщо щось змінено, спершу спитає: `y` викинути, `s` зберегти, `n` повернутися |
| `ctrl+e` | відкрити `config.yaml` у `$VISUAL` / `$EDITOR` |

Поле «Ключі» — список шляхів через кому.

Неправильне значення (наприклад, ширина 2632 чи `lots` у scrollback) не
зберігається: внизу з'являється помилка, а екран лишається відкритим.

Під час збереження файл записується **заново разом із поясненнями**. Якщо ти
дописував у нього власні коментарі, вони не збережуться.

## Мова

Інтерфейс і документація є українською та англійською.

| `language` | Що буде |
|---|---|
| `auto` | за локаллю: перша непорожня з `LC_ALL`, `LC_MESSAGES`, `LANG`; `uk_*` (напр. `uk_UA.UTF-8`) — українська, решта — англійська |
| `uk` | українська |
| `en` | англійська |

Мова перемикається **одразу** після збереження налаштувань: підписи, статус-рядок,
діалоги, вбудована довідка (`ctrl+a ?`). Повідомлення, які вже надруковано у
вкладці (наприклад, `Підключення до …`), лишаються такими, як були; нові з'єднання
пишуть новою мовою.

Коментарі в `config.yaml` теж пишуться вибраною мовою, коли файл зберігається.

Кілька речей лишаються англійською завжди: назви параметрів у YAML, клавіші,
технічні помилки від бібліотек і з `sessions.yaml` (наприклад, `yaml: line 3: …`).

Документація: українська в [`docs/uk/`](.), англійська в [`docs/`](../).

## Кольорові схеми (Catppuccin)

| `theme` | Що буде |
|---|---|
| `terminal` | як було: sshdeck бере кольори й фон твого термінала |
| `latte` | [Catppuccin](https://catppuccin.com/palette) Latte, світла |
| `frappe` | Catppuccin Frappé, темна, найм'якша |
| `macchiato` | Catppuccin Macchiato, темна |
| `mocha` | Catppuccin Mocha, найтемніша |

Схема Catppuccin фарбує **все вікно**, а не лише рамки sshdeck:
- фон і текст: `base` і `text` вибраної палітри;
- дерево, вкладки, статус-рядок, діалоги й поля вводу мають кольори палітри;
- **програми у вкладках** теж: 16 ANSI-кольорів (`ls --color`, запрошення
  shell, `git diff`) стають кольорами палітри, так само як у
  Catppuccin-темах для терміналів; `red` стає `red` палітри, `blue` — `blue` і т.д.;
- курсор має колір `rosewater`;
- довідка (`ctrl+a ?`) теж у кольорах палітри.

Кольори, які програма задає явно (256 кольорів або truecolor, наприклад тема
vim), лишаються такими, як вона задала. Програми, що питають термінал про фон
(vim з `background=auto`), отримують фон палітри.

На екрані налаштувань схема **показується одразу**, поки ти перебираєш варіанти
`← →`. `ctrl+s` її зберігає, а `esc` → `y` повертає попередню.

**Truecolor.** Палітри задані в 24-бітних кольорах. Сучасні термінали
(kitty, WezTerm, Alacritty, GNOME Terminal, Konsole, Windows Terminal, iTerm2)
їх підтримують. Якщо термінал має лише 256 кольорів, sshdeck сам підбирає
найближчі, але відтінки будуть грубіші. Якщо sshdeck запущено всередині tmux,
дозволь tmux передавати truecolor:

```
# ~/.tmux.conf
set -as terminal-features ",*:RGB"
```

і перевір, що `COLORTERM=truecolor` (більшість терміналів виставляє його самі).

## Prefix і tmux

Якщо на серверах (або локально) ти користуєшся tmux з prefix `ctrl+a`, виникає
конфлікт:
- **tmux на сервері, всередині вкладки.** `ctrl+a` перехоплює sshdeck. До tmux
  його можна передати подвійним `ctrl+a ctrl+a`, але це незручно.
- **sshdeck всередині локального tmux.** Клавішу першим забирає tmux.

Рішення: дати sshdeck іншу клавішу, наприклад `ctrl+]` (майже ніде не зайнята),
`ctrl+\` або `alt+a`. Тоді `ctrl+a` повністю належить tmux.

## Ручне редагування

- Файл можна правити будь-яким редактором, у тому числі через `ctrl+e` на екрані
  налаштувань. Після виходу з редактора файл перевіряється і застосовується
  одразу.
- Якщо в ньому помилка, лишаються попередні налаштування, і показується, що не
  так.
- Якщо `config.yaml` зламаний ще до запуску, sshdeck стартує зі значеннями за
  замовчуванням і показує помилку
  `… — працюю з типовими налаштуваннями, виправ через ctrl+a ,`
  (англійською: `… — using defaults, fix it with ctrl+a ,`). Збережи налаштування через
  екран, і файл перезапишеться правильним.

Невідомі параметри у файлі ігноруються. Відсутні параметри беруть значення за
замовчуванням.
